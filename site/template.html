Protein function annotation · benchmark replication

How much of ProFAB's performance depends on close relatives between training and test sets

A re-run of the ProFAB benchmark protocol on its bundled Gene Ontology and Enzyme Commission tasks, with random, similarity-based and temporal splits compared on the same footing, and the effect of near-duplicate proteins measured directly.

Source benchmark Özdilek et al., Briefings in Bioinformatics 24(2), bbac627 (2023)Data ProFAB repository, four bundled tasksCompute CPU only, {{n_cfg}} configurations on official splits

SummaryWhat the re-evaluation shows

ProFAB provides ready-made protein sets for GO terms and EC numbers, with random, similarity-aware and temporal train/test splits. This study runs {{n_desc}} sequence descriptors and {{n_clf}} classifiers on every usable split of the four tasks that ship with the repository, then holds the protein pool fixed and changes only how the folds are drawn.

Scope. The repository bundles four of the platform's datasets; the project server that hosts the rest was not reachable from the analysis environment. Study designTasks, descriptors, classifiers and statistics

Each task is a binary problem: proteins annotated with a GO term or EC number against sampled negatives. Positives make up one third of the GO pools and about one quarter of the EC pools. Splits are the ones ProFAB ships as index files, so train and test membership is not re-drawn.

Classifiers

Logistic regression, RBF support vector machine, k-nearest neighbours, random forest, histogram gradient boosting, Gaussian naive Bayes and a one-hidden-layer MLP. Features are standardised inside the model pipeline for every method except the tree ensembles. Regularisation strength (logistic regression, SVM) and neighbour count (k-NN) are tuned by inner 3-fold cross-validation on the training set only, scored by AUROC. The other four use fixed settings. ProFAB tunes hyperparameters for all of its algorithms automatically, so this is a lighter protocol than the original. Temporal validation proteins are merged into the training set before tuning.

Metrics and uncertainty

Matthews correlation coefficient is the primary metric because positives are the minority class. AUROC, average precision (AUPRC), accuracy, balanced accuracy, precision, recall, specificity and F1 are reported alongside. Every test-set metric carries a stratified bootstrap 95% interval (500 resamples). Differences between split types use matched (task, descriptor, classifier) triples, a percentile bootstrap (4,000 resamples) on the mean difference, and a Wilcoxon signed-rank test.

MCC = (TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN)) AUPRC = Σₙ (Rₙ − Rₙ₋₁) · Pₙ (step-wise average precision)

Similarity proxy

Sequences are not available offline, so closeness between two proteins is the cosine similarity of their mean-centred descriptor vectors, written τ when used as a threshold. Conjoint triad is the default space because it is composition-based and independent of the k-PSSM profile. Cosine values measured in different descriptor spaces are not on one scale: compare splits within a space, not spaces with each other.

Controlled experiments

  • Same-pool cross-validation. Each task's random-split pool is cross-validated in five folds, either with ordinary stratified folds or with stratified group folds. Groups are the connected components of the graph that links proteins at similarity ≥ τ, so no held-out protein has a training neighbour at or above τ. Random folds are repeated four times and grouped folds twice per τ.
  • Leakage pruning. For each test fold, training proteins at or above τ to any test protein are removed. A control removes the same number of randomly chosen training proteins (three draws).
  • Cross-space grouping. Groups are built in conjoint-triad space or in k-PSSM space and every descriptor is scored under both.

Data and split auditWhat the split files contain

In the splits audited here no accession appears in both train and test. Positive rates are preserved between train and test within each split. Exact duplicate AAC vectors do occur across the random splits ({{dup_random}} test proteins in total) and not in the similarity splits.

Index files that do not fit their feature files

ProFAB stores train, test and validation membership as row positions. For the temporal split of EC 1.2.7 a large share of those positions lie beyond the end of the feature file. ProFAB's own loader skips such rows without a message, so the shipped temporal split for this task contains an unknown subset of its intended proteins. It is excluded from every result here.

Table 3. Index entries that point past the end of the feature file

k-PSSM files are offset from the other descriptors

The index files are shared by all descriptors, but the k-PSSM files are not row-aligned with the others. The first mismatch is at row 0 in all 16 files, each file lists one accession twice, and a few accessions are truncated or missing. Applied by position, the same index selects different proteins for k-PSSM than for AAC or conjoint triad. This study resolves every index on the AAC file and joins the other descriptors by accession. Section 7 measures what the stock behaviour changes.

LimitationsWhat the results cannot support

  • Four tasks. The conclusions rest on two GO terms and two EC numbers. The similarity split exists for three of them and the temporal split for one usable task. Test sets range from 24 to 543 proteins.
  • Similarity is a proxy. Thresholds are cosine values in descriptor space and do not map to percent sequence identity. A run with MMseqs2 or CD-HIT clusters at fixed identity would need the sequences, which the shipped files do not contain and which could not be downloaded here.
  • Single-linkage groups. At the lowest thresholds the largest group holds up to {{giant_max}} of a task's proteins, which limits how strict the folds can become. Grouped folds can therefore differ slightly in training size from random folds.
  • Lighter tuning. Four of seven classifiers use fixed hyperparameters and the controlled experiments use fixed settings throughout. Rankings among classifiers may change under the full ProFAB tuning.
  • No published numbers. The article's tables were not accessible, so agreement with the reported scores is untested.
  • Descriptor provenance. The k-PSSM features are used as shipped. How the PSSMs were generated, and why some rows are shifted or missing, is not documented in the repository.
  • Temporal comparison. One task, different pool composition from the random split (about one third of proteins shared), and a split that ProFAB builds from annotation time. The causal story for its near-chance composition results is a hypothesis.

ReproducibilityCode, seeds and files

Everything runs on two CPU cores in roughly one hour. Random seed 42 is used for model initialisation, bootstrap and tuning folds; fold-set seeds are listed in each script.
